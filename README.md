# BritalNet - High-Speed ISP Management System

BritalNet is a modern, responsive ReactJS web application designed for a local Internet Service Provider based in Brital/Baalbek. This project focuses on providing a premium user experience with high-speed performance and modern aesthetics.

## Features

- **Dynamic Navigation**: Smooth routing between Home, About, Plans, Coverage, and Support pages.
- **Modern UI**: Built with ReactJS, Tailwind CSS, and Framer Motion for premium animations.
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices.
- **Glassmorphism Design**: Elegant card layouts and translucent headers.
- **Interactive FAQ**: Dynamic support section for user queries.

## Technologies Used

- **Frontend Framework**: ReactJS (Vite)
- **Styling**: Tailwind CSS & Vanilla CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Routing**: React Router DOM

## Setup Instructions

1. **Clone the Repository**
   ```bash
   git clone [repository-url]
   cd project-directory
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Run Development Server**
   ```bash
   npm run dev
   ```

4. **Build for Production**
   ```bash
   npm run build
   ```
